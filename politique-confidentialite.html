Données collectées et finalités

Nous collectons uniquement les données strictement nécessaires aux finalités suivantes :

  • Formulaire de contact / devis — nom, téléphone, email, code postal, type de demande, description du besoin. Finalité : répondre à votre demande, établir un devis, planifier une intervention. Base légale : exécution de mesures précontractuelles à votre demande (art. 6.1.b RGPD).
  • Échanges téléphoniques et par email — coordonnées et informations communiquées spontanément. Finalité : traiter votre demande, conserver une trace contractuelle. Base légale : exécution du contrat (art. 6.1.b) ou intérêt légitime (art. 6.1.f).
  • Facturation — nom, adresse, prestations, montants. Finalité : obligations légales comptables et fiscales. Base légale : obligation légale (art. 6.1.c).

Aucune donnée n'est collectée à votre insu. Aucun profilage publicitaire n'est réalisé.
